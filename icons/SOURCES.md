# Icon sources

Brand marks belong to their owners and are shown only to name the tools used.

- **Simple Icons** (CC0): every brand icon except LinkedIn.
  `https://raw.githubusercontent.com/simple-icons/simple-icons/develop/icons/<name>.svg`
- **Devicon** (MIT, `LICENSE-devicon.txt`): `linkedin.svg`, from
  `icons/linkedin/linkedin-plain.svg`. Simple Icons removed LinkedIn.
- **Lucide** (ISC, `LICENSE-lucide.txt`): the `lucide-*.svg` files.

eSewa, Khalti and Recharts have no icon in these sets, so their chips use a
dot in the brand colour.
